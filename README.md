# Diabetes Risk Screening & Clinical Analytics App

## Project Overview
This project focuses on analysing diabetes-related health data and developing machine learning models to estimate diabetes risk based on clinical measurements.

It combines data analysis, preprocessing, statistical testing, machine learning, and an interactive Gradio application.

## Objectives
- Explore and analyse diabetes-related clinical data.
- Perform data cleaning and preprocessing.
- Identify relationships between clinical features and diabetes outcomes.
- Train and compare machine learning models.
- Develop an interactive diabetes risk screening application.

## Dataset
**Dataset:** Pima Indians Diabetes Dataset

**Source:** https://raw.githubusercontent.com/jbrownlee/Datasets/master/pima-indians-diabetes.data.csv

- 768 records
- 8 input features
- 1 target variable (`Outcome`)

## Machine Learning Models
1. Logistic Regression
2. Gaussian Naive Bayes

## Project Structure
- `data/` – Dataset information
- `notebooks/` – Project Jupyter notebook
- `src/` – Source code
- `docs/` – Project documentation and report

## Application
An interactive Gradio application accepts clinical measurements and displays predictions from both trained models.

## Disclaimer
This project is developed for educational purposes only. Its predictions are not medical diagnoses and should not replace professional medical advice.
